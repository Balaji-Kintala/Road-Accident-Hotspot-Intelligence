# Data

This folder contains the cleaned datasets used for the Road Accident Hotspot Intelligence project.

## Datasets

- `road_classification_cleaned.csv` — Road classification-wise accident, injury, and death data.
- `time_occurrence_cleaned.csv` — Time-of-occurrence-wise road accident data.

## Source

National Crime Records Bureau (NCRB), Accidental Deaths & Suicides in India (ADSI) 2023.

The datasets were cleaned and transformed using Python and Pandas before analysis.
